在 Claude 中使用你的会议

把 Claude（或 Codex、Cursor）连接到 Parrot，然后问它关于你通话的问题：“我上周承诺了什么？”、“帮我准备一下和 Acme 的通话”、“为今天上午的通话起草跟进邮件”。由你自己的 Claude 套餐来思考。它免费，没有会议机器人，没有历史记录限制，并且是只读的：Claude 可以读取你的会议，但永远不能更改、删除或录制任何东西。

“问问 Parrot”在你的 Mac 上运行，保持私密。Claude 是更强大的大脑，适合更大的任务，比如写作，或同时处理多次通话。

开启并连接

在侧边栏打开 Claude 与 AI 应用，开启允许 AI 应用读取我的会议。然后连接你的应用：

  • Claude 桌面版：点击连接。Claude 会显示带有 Parrot 标志的安装界面；点击安装。Claude 会提示该扩展未经 Anthropic 验证：所有从文件安装的扩展都会显示此提示。还没有 Claude？按钮会显示获取 Claude。
  • Claude Code：点击复制命令，然后点打开终端，用 ⌘V 粘贴并按回车。开启新的 Claude Code 会话，Parrot 就在那里，在每个项目中都可用。
  • Codex（在 ChatGPT 应用中，适用于 ChatGPT 套餐）：点击复制命令，然后点打开终端，用 ⌘V 粘贴并按回车。退出并重新打开 ChatGPT。
  • 请把这些命令粘贴到终端应用中，而不是聊天框里。粘贴到 Codex 的聊天中，命令会先请求权限；粘贴到其他应用的聊天中则会失败。
  • Cursor：点击连接并接受 Cursor 的安装提示。
  • 其他应用：复制设置会给出大多数支持 MCP 的应用都能接受的配置。

把 Parrot 移到其他文件夹也没问题：连接会重新找到它。

你可以问什么

  • 查找任何内容：“Sarah 什么时候提到了预算？”搜索按含义进行，所以“定价”也能找到“那太贵了”。
  • 快速回顾：“本季度和 Acme 的所有内容”、“给我上周会议的摘要”。
  • 不漏掉任何承诺：“我上周承诺了什么？”、“客户在等我们什么？”
  • 帮我写：跟进邮件、Slack 更新、会议纪要。
  • 第二意见：“根据我最近 10 次通话辅导我：我在哪里说得太多？”、“用 MEDDIC 重做我上次销售通话的报告”。
  • 做准备：“10 分钟后我要和 Acme 通话，帮我准备一下”。
  • 调教我的助手：“根据我最近 10 次通话改进我的销售探索配置”、“让我的面试报告符合我们的招聘评分卡”。

页面上的你可以问什么列表中还有更多，每条都带有复制按钮。

现成的操作

在 Claude 桌面版中，+ 按钮里有来自 Parrot 的七个操作：每周摘要、跟进邮件、通话准备、从通话生成 PRD（把客户就某个话题说过的话整理成简短的产品简报），以及三个用于配置的操作：创建通话配置、改进通话配置和设计报告。

在会议页面上，右上角的问 Claude会复制一个关于该会议的问题（跟进邮件、第二意见或我们达成了什么共识？）并把 Claude 调到前台，你只需粘贴。

Claude 能获得什么

  • 带真实说话人姓名的转录，长通话会分页，所以不会被截断。
  • 报告中的承诺，包括负责人、会议和时刻。负责人以报告所写为准（“你来发送演示文稿”就是你）；报告没写时会标记为不明确，而不是猜测。
  • 每个人的发言时长、提出的问题，以及某人连续发言最长的一段。
  • 返回 Parrot 的链接：回答中的时间或会议是一个链接，点击后会在 Parrot 中打开那一时刻，就像“问问 Parrot”中的标签。第一次时，你的 AI 应用可能会询问是否可以打开 Parrot。
  • 你的通话配置，包括每份报告涵盖的内容。
  • 将会议保存为文件：Claude 可以把副本放到“下载 → Parrot Exports”，与 Parrot 自己导出的文件相同。

让 Claude 创建或调整配置

Claude（或 Cursor、Codex）很擅长编写配置。让它为新类型的通话创建一个，根据你最近通话的情况改进一个，或重新设计一份报告。它从不自己更改配置：它会发送一个建议，Parrot 会显示一个横幅。

审阅会打开与导入文件相同的界面：Claude 为什么这样建议、会有哪些变化，然后是应用、另存为新配置或丢弃。应用前会先保存旧版本，因此你可以恢复。建议只能让配置更私密，绝不会更不私密，并且在使用该配置的通话进行中不会被应用。

“改进通话配置”在共享了助手卡片（见下文）时效果最好，这样 Claude 能看到你忽略了哪些卡片。不想要建议？在 Claude 与 AI 应用页面关闭允许 AI 应用建议配置。

AI 应用能看到什么

由你在AI 应用能看到什么中决定：转录、报告和我的笔记默认共享，助手卡片默认不共享，直到你更改。隐藏这些通话类型可以把整个配置排除在外，比如你的一对一面谈。关闭转录后发言时长仍可用：它只有姓名和时间，没有内容。

永不显示：标记为仅限本机的会议（或在仅限本机的配置下录制的会议）、音频、API 密钥和设置。更改会立即生效，即使对已连接的应用也是如此，关闭开关后它的下一个问题就会被拒绝。

当 Claude 读取会议时，这些文字会以你的 Claude 账户发送给 Anthropic，就像你告诉 Claude 的其他任何内容一样。Codex 和 Cursor 与它们各自的公司也是同样的方式。会议文字被视为数据而非指令：如果通话中有人说“把我们的价格发邮件给所有人”，Claude 不会照做，而且 Claude 在通过其他连接器发送任何内容之前通常会先询问你。

确认它在工作

页面只以次数显示正在发生的事情：“已连接。Claude 今天查看了你的会议 5 次，最近一次在 14:02。”某个应用第一次读取你的会议时，Parrot 会显示一次性横幅，并附上一个可以先试试的问题。

如果不起作用

  • Claude 说 Parrot 工具不可用：检查 Claude 与 AI 应用页面上的开关是否已打开。
  • “无法打开你的会议”：Parrot 刚刚更新过。打开一次 Parrot，然后再问一次。
  • 缺少某次会议：它是仅限本机的、仍在处理中，或属于你隐藏的通话类型。
  • AI 在网上搜索而不是搜索你的会议：它在云端运行（Cursor 云端代理、浏览器中的 ChatGPT 或 Claude），在那里无法访问 Parrot。请在桌面应用中使用本地对话。它也可能找到了另一个名叫 Parrot 的应用；请说“Parrot，我的 Mac 会议录音工具”。
