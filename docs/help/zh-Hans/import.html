导入录音

有语音备忘录、Zoom 录像或者以前的访谈？把音频文件拖到 Parrot 窗口的任意位置，或使用“文件 → 导入音频”。Parrot 会把文件复制进来，在你的 Mac 上完整转录，识别谁在说话，然后生成和实时通话相同的报告。它会显示为一次普通会议，日期按文件本身的日期而不是今天，这样上周的录音看起来仍然是上周的。

须知

  • 大多数格式都可以：m4a、mp3、wav、aac、caf。只要 Mac 能播放，Parrot 基本都能处理。
  • 导入的文件是一条混合音轨，因此区分说话人依靠的是声音差异，而不是实时通话那种干净的双轨分离。效果还不错，你也可以在会议中重命名说话人。
  • 正在实时录音时，导入会等待。一个 Whisper，一次只做一件事。
  • 如果导入失败，打开它看看：“报告”标签页会说明原因，例如“此文件中没有发现语音”或文件无法读取。后一种情况请确认文件能在 QuickTime 中播放，再将其另存为 M4A 或 WAV 后导入。
