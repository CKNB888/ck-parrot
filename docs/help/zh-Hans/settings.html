设置逐页说明

从侧边栏打开设置（或按 ⌘,）。左侧是主题，每个主题一页。任何地方都没有“保存”按钮：每项更改在你做出的瞬间就会保存，一个小小的“已保存”标签会确认这一点。

通用

登录时打开 Parrot会在你登录时启动 Parrot，好让它察觉你的第一次通话。它就是普通的 macOS 登录项，列在“系统设置 → 通用 → 登录项”中。开启关闭窗口时从程序坞隐藏后，窗口关闭期间 Parrot 只待在菜单栏；在菜单栏中选择打开 Parrot，程序坞图标会随窗口一起回来。接下来是外观（跟随系统，或强制浅色或深色）、音频文件在磁盘上的位置以及“在访达中显示”按钮，还有你正在运行的版本。更新会自动处理：“保持 Parrot 为最新”会在后台下载新版本，并在你退出时安装，绝不会在录音期间进行；“立即检查”会马上查找。更新准备好后，Parrot 会通过通知提示一次；立即重启会马上安装，但绝不会在通话中或撰写报告时进行。更新后，主页会显示一张简短的新功能卡片，点阅读完整内容可查看完整的更新日志。还有一个“打开用户指南”链接打开本指南，一个“显示欢迎导览”链接重新播放首次运行设置（权限和模型选择），主题列表底部有一行关于（那是我在向你问好），以及同样打开指南的小问号按钮。

录音

这里有一个重要的开关：回声消除。如果你用扬声器通话，请保持开启；它会从你的麦克风听到的声音中减去对方的声音，这样他们的话就不会被当成你的再写一遍。仍可能有微弱的残留，因此回放通话时，在只有对方说话的时候 Parrot 会调低你这一侧的音量。使用耳机时没有什么需要消除的，可以关闭它。

下方是：通话检测（通话开始时 Parrot 是询问、自动录音还是什么都不做，以及你让它忽略的应用）、日历（连接、Parrot 读取哪些日历、助手是否可以读取邀请，或你是否希望在会议前收到提醒），以及收藏（⌃⌥M 快捷键）。这三项都在录制通话中有说明。

连接

通话后会议去往何处：Markdown 笔记文件夹（Obsidian 很合适）、每次通话后的跟进邮件草稿、发送到 Zapier、Make 或 n8n 的 webhook，以及 Claude 和其他 AI 应用的开关，并附有其专属页面的链接。详见连接和在 Claude 中使用你的会议。

隐私

仅限本机（适用于每次通话，或在“配置”中按配置设置）、对云端 AI 隐藏个人信息、你的录音同意提示，以及自动清理旧音频和会议。参见哪些数据会离开你的 Mac。

转录

关于语音如何变成文字的一切：

  • 模型：由哪个本机模型完成工作。Parakeet v3 最快，但只支持 25 种欧洲语言（不含土耳其语）；其他语言会自动切换到 Whisper（参见 Parakeet 与其他语言）。Whisper 模型中，base 速度快，large-v3-turbo 是 Apple 芯片上的精度之选，其 626 MB 的压缩版本精度几乎相同，内存占用却少得多。切换时会下载一次新模型。
  • 语言：默认自动检测。如果你的通话总是同一种语言，请设置它；语言出错的意外就会消失。如果 Parrot 在通话中听到不同的语言会提醒你。使用 Deepgram 时，请按名称选择土耳其语、阿拉伯语、中文或韩语：它的自动检测会跳过这些语言。
  • 自定义词汇：你的人名和行话，用逗号分隔，这样它们就不会再被“创造性地”拼错。参见实时转录。
  • 引擎：本机是默认的私密选择。Groq 和 Deepgram 是需要手动开启的云端引擎，需要你自己的密钥，并且会把音频发送出去；如果它们出错，Parrot 会回退到本机。
  • 每次通话后润色转录：可选，在你按下停止后通过 Groq 重新转录保存的音频，在生成报告之前用更干净的版本替换实时转录。
  • 说话人识别：区分不同声音的小型本机模型、实时说话人标签（实验性：在通话中而不仅是通话后为对方命名）以及记住声音。参见报告。
  • 边说边显示文字：当前说话人说到一半时在其下方填充的灰色预览。它是草稿，下一次停顿时会被完成的句子替换。如果通话时你的 Mac 发烫，可以关闭它；无论开关与否，保存的转录都完全一样。

助手

AI 层的总开关、决定费用的节奏和对话窗口控制，以及驱动实时卡片和报告的模型（两者可以不同）。问问 Parrot 选择回答你关于过往通话问题的 AI（除非你更改，否则与报告相同）。参见问问 Parrot。第一次用？设置助手会在几分钟内带你完成私密、均衡或云端的设置。本页有专门的指南：服务商见设置助手，控制选项见通话中的助手。

API 密钥

Claude、Groq、Deepgram 和 TypeSafe AI 的密钥，每项一个输入框。它们保存在 macOS 钥匙串中，而不是文件里，除了与各自的服务通信外绝不会离开这台电脑。粘贴即可。（其他 AI 服务的密钥在助手页面上，紧挨着它的地址。）

知识库

助手可以据以回答的文档，按文件夹组织，每个都有用于设置和说明行。完整说明见知识库。

配置

最深入的一页，有专门的指南：通话配置。你在这里逐张卡片地定制助手要关注的内容。
