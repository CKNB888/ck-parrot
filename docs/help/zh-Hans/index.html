Parrot 帮助

一款把一切都留在你 Mac 上的通话录音工具。

Parrot 会录下通话双方的声音，在你说话时写出转录，并且（如果你愿意）让助手——一个和你一起关注对话的 AI——在旁协助。一切都在你自己的电脑上运行。除非你接入自己的 AI 密钥，否则不会有任何数据离开；即便接入，也只发送转录文字，绝不发送音频。

主题

  • 快速上手 安装、两项 macOS 权限、选择模型。
  • 录制通话 开始、停止、会录下什么，以及为什么通话中途退出也没关系。
  • 通话界面逐项说明 通话中屏幕上每一部分的导览，以及要留意什么。
  • 实时转录 句子如何出现、语言、教它认识你的用词。
  • 设置助手 Claude、通过 Ollama 运行的本地模型，或你自己的服务器。
  • 通话中的助手 卡片、关闭助手，以及控制费用。
  • 报告与费用 通话后的总结、辅导，以及每次会议的花费。
  • 问问 Parrot 询问关于过往通话的任何问题；每个回答都链接到对应时刻。
  • 在 Claude 中使用你的会议 一键连接 Claude、Codex 或 Cursor；跨所有通话提问。
  • 连接 Markdown 与 Obsidian、跟进邮件、提醒事项、Webhook。
  • 设置逐页说明 用大白话解释每一个设置页面。
  • 通话配置 按类型定制助手的卡片。最深入的一篇。
  • 知识库 让助手根据你自己的文档回答。
  • 导入录音 把已有的音频文件变成一次会议。
  • 故障排除 通话中麦克风突然没声、模型加载卡住等问题。
  • 哪些数据会离开你的 Mac 诚实的清单。它很短。
  • 来自 Uygar 的问候 谁做了这个，以及为什么。
