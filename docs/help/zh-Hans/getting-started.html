快速上手

安装

从发布页面下载最新的 DMG，打开后把 Parrot 拖进“应用程序”。就这样。如果你更想从源码构建，克隆仓库并运行 make run。

两项权限

首次启动时，Parrot 会引导你授予两项 macOS 权限。点击每个深色按钮，回应系统对话框，这一行会自动变成绿色对勾。正常录制通话两项都需要：

  • 系统音频录制。Parrot 借此听到通话的另一方。在 macOS 15 及更新版本上，这是一项仅限音频的权限：Parrot 完全不会请求屏幕访问。在 macOS 14 上，同样的工作要通过传统的“屏幕录制”权限完成；这常让人意外，所以坦白解释一下：这只是旧版 macOS 提供系统音频的方式。无论哪种情况，Parrot 都不会捕获你的屏幕内容，只捕获声音。
  • 麦克风。你这一方的声音。
注意：在 macOS 14 上，“屏幕录制”权限要在应用重启后才生效。如果授权后这一行没有变成绿色对勾，请退出 Parrot 再重新打开。macOS 就是这样。macOS 15 及以上无需重启；Parrot 第一次听到会议音频时这一行会自动确认。

认识助手

接下来是一个简短示例，展示助手在通话中做什么：当对方提问时，它会根据你自己的文档建议回答，把关键阻碍置顶直到你处理，实时打分，并在通话后撰写报告。只有你能看到它；不会有机器人加入你的通话。

选择助手的工作方式

  • 私密。一切都留在你的 Mac 上，而且免费。Parrot 会为你安装 Ollama 应用（约 200 MB；macOS 会让你确认一次）并下载一个模型。下载期间你可以继续操作；完成后助手会自动开启。
  • 均衡。推荐。音频留在你的 Mac 上，只有文字发送给 Claude。粘贴 Claude 密钥并点击“检查密钥”。
  • 云端。Deepgram 实时写出文字，Claude 运行助手。需要 Claude 密钥；Deepgram 密钥可选。

还没想好？选稍后决定。主页上的卡片让你随时设置助手，“设置 → 助手 → 设置助手”也可以。

语音转文字

转录在你的 Mac 上进行。Parrot 会挑选适合你 Mac 的模型并立即开始下载。Parakeet v3 最快，但它只支持 25 种欧洲语言，不包括土耳其语，因此只有当你 Mac 的语言（以及你过往的通话，如果有的话）都符合时 Parrot 才会推荐它。否则它会选择 Whisper：12 GB 及以上内存的 Mac 用 Large V3 Turbo，更小的用 Base。Large V3 Turbo Compressed 介于两者之间：精度接近大模型，下载量只有三分之一。关闭设置窗口后下载会继续，录音按钮会等到下载完成。之后转录可以离线工作。

你可以随时在“设置 → 转录”中切换模型。

在 Claude 中使用你的会议

接近尾声时，导览会展示如何向 Claude、Cursor 或 Codex 询问你的通话。连接 Claude 会开启允许 AI 应用读取我的会议并打开 Claude 的安装界面：在那里点击“安装”。继续会跳过此步，Cursor、Codex 和 Claude Code 可以随时从侧边栏的Claude 与 AI 应用连接。

这是 Parrot 中唯一不像其他部分那样私密的功能。当你提问时，该应用读取的内容会以你的账户发送给其公司（Anthropic、OpenAI 或 Cursor 的 AI 服务商）。在你连接之前它保持关闭，并且从不接触音频、API 密钥或仅限本机的会议。如果你选择了私密，导览会略过这一步。详见在 Claude 中使用你的会议。

就这些

漏看了什么，或者设置到一半退出了？在你完成之前，Parrot 会自动再次显示导览，你也可以随时从“帮助 → 显示欢迎导览”重新播放。

按下大大的录音按钮开始说话。转录会随着你说话出现。想了解 Parrot 的 AI 部分时，请阅读设置助手。它是可选的，默认关闭。
