设置助手

助手是 AI 层：通话中的实时建议卡片，以及通话后的报告。它默认关闭，没有它 Parrot 作为录音和转录工具也完全够用。需要时，在“设置 → 助手”中打开它，并选择由谁来思考。

三种驱动方式

最快的方法是引导式设置：“设置 → 助手 → 设置助手”，或主页上的助手卡片。它会带你选择私密（在你的 Mac 上运行 Ollama，自动安装）、均衡（Claude，音频留在你的 Mac 上）或云端（Claude 加 Deepgram），并在保存前检查你的密钥。

  • Claude（云端）。最聪明的选择。你需要自备 API 密钥（设置 → API 密钥），通话期间转录文字会发送给 Anthropic，音频永远不会。每次通话都会产生费用；Parrot 会在每次会议上准确显示花了多少。
  • Ollama（本地）。免费且完全私密，AI 在你的 Mac 上运行。引导式设置会为你安装 Ollama，你也可以自己安装后在 Parrot 设置中选择模型。如果模型尚未下载，Parrot 会提供带进度条的下载。实话实说：本地卡片明显比云端的慢，因为模型要和实时转录共享你的 Mac。用来写报告很好；实时卡片则请预期从容的节奏而不是即时响应。在 Apple 芯片上请使用原生版本，否则会非常慢。
  • 其他 AI 服务。任何兼容 OpenAI API 的服务：OpenRouter、OpenAI、Groq、你自己的机器或公司网关。粘贴其地址、模型名称和你的密钥。如果你使用的是限制严格的免费套餐，下一篇中的节奏设置正是为你准备的。

使用 OpenRouter

OpenRouter 让你用一个密钥访问众多模型，包括便宜又快速的模型，在你的 Mac 跑本地模型太慢时很好用。

  1. 在 openrouter.ai 创建一个密钥。
  2. 在设置 → 助手 → 模型中选择其他 AI 服务。将服务器地址设为 https://openrouter.ai/api/v1，将模型设为其列表中的模型 ID，例如 google/gemini-2.5-flash。
  3. 在 API 密钥中粘贴密钥。

转录文字会发送到 OpenRouter 和你选择的模型，与 Claude 的情况一样。Parrot 无法在此估算费用，请在 OpenRouter 上查看用量。

根据你的文档即时回答

使用 Claude 时，还有一个可选附加项：TypeSafe AI 密钥（设置 → API 密钥）。有了它，当对方问到你文档中涵盖的内容时，Parrot 会以“来自你的文档”卡片显示匹配的摘录，通常在一秒内，而 Claude 仍在撰写回答。随后 Claude 的卡片会接替。没有该密钥则一切照旧。它会把问题、几行上下文和你文档中匹配的片段发送给 TypeSafe，绝不发送音频，并且只查看用于中包含你当前通话配置的文档。

不同任务用不同的大脑

实时卡片需要快速而敏锐。通话后报告则有充足的时间。所以 Parrot 允许你为两者分别选择后端：常见组合是实时卡片用 Claude、报告用本地模型，这样报告免费且私密，又不会拖慢通话。如果你只设置了一个，两项任务都用它。
